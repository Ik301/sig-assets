# sig-assets

Static image assets for an email signature: the Princeton University shield + wordmark lockup.

| file | use |
|---|---|
| `princeton-lockup-white.png` | 400px wide (displays at 200px), white background, 10px padding. Works on light and dark mail backgrounds. |
| `princeton-lockup-transparent.png` | Same artwork, transparent background. For light backgrounds only (a black logo disappears on dark). |

Served over GitHub Pages. Delete this repo if you stop using the signature.
